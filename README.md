# Анализ тональности обращений граждан
Система автоматического определения эмоциональной тональности русскоязычных текстов обращений граждан в органы местного управления, на основе дообученной BERT-модели.

## 📋 Обзор

Проект реализует решение для анализа тональности коротких жалоб (~50 слов) и развернутых многочастных обращений (~200-300+ слов). Система способна классифицировать тексты на три класса:
- **Нейтральное (0)** - Официальные заявления, сбалансированная информация
- **Положительное (1)** - Благодарность, одобрение, похвала
- **Отрицательное (2)** - Жалобы, критика, требования

## 🎯 Практическая применимость

- ✅ Автоматическая категоризация обращений по эмоциональной окраске
- ✅ Мониторинг удовлетворённости услугами органов власти
- ✅ Выявление проблемных тем через анализ частоты негативных обращений
- ✅ Оценка эффективности мероприятий по динамике тональности
- ✅ Интеграция с системами обработки обращений граждан

### Технический стек

- **Фреймворк:** PyTorch + Transformers (Hugging Face)
- **Базовая модель:** [ai-forever/ruBert-base](https://huggingface.co/ai-forever/ruBert-base) (104M параметров)
- **Обучающий датасет:** [Russian Sentiment Dataset](https://www.kaggle.com/datasets/mar1mba/russian-sentiment-dataset) (290,458 текстов)
- **Язык:** Python 3.x, Jupyter Notebook

## 📊 Ключевые метрики

### На тестовом наборе (43,569 примеров)
- **Общая точность (Accuracy):** 76.2%
- **Точность по классам:**
  - Neutral: Precision 0.71, Recall 0.65, F1-score 0.67
  - Positive: Precision 0.86, Recall 0.88, F1-score 0.86
  - Negative: Precision 0.76, Recall 0.79, F1-score 0.77

### На размеченных обращениях граждан (12 примеров)
- **Точность:** 83.3%
- Успешно определяет чётко положительные и отрицательные тексты
- Проблемы с смешанной тональностью 

### На длинных текстах (5 примеров, 200-300 слов)
| Стратегия обработки | Точность | Уверенность | Применение |
|---|---|---|---|
| **Truncate** (обрезание) | 60% | 93.8% | Быстрая обработка |
| **Average** (усреднение) | 80% | 88.1% | Рекомендуется по умолчанию |
| **Summary** (начало/середина/конец) | 80% | 84.0% | Структурированные документы |

## ⚙️ Параметры модели 

| Параметр | Значение | Почему |
|---|---|---|
| learning_rate | 5e-05 | Оптимальна для BERT fine-tuning, базовые модели обычно обучают с 2e-5 до 5e-5 |
| num_epochs | 3 | Больше эпох → переобучение, меньше → недообучение |
| max_length | 256 | Баланс между памятью и контекстом; 512 требует 2x больше памяти |
| batch_size | 16 | Оптимальна для GPU с 6-8GB памяти |
| seed | 42 | Обеспечивает воспроизводимость результатов |

## ⚠️ Ограничения и будущие работы

### Текущие ограничения
- Модель обучена на отзывах, не на обращениях граждан
- max_length=256 требует специальной обработки для длинных текстов
- Нет поддержки других языков
